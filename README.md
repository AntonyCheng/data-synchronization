# Data Synchronization Platform

MySQL binlog CDC to PostgreSQL synchronization platform MVP.

## Project Layout

- `server/`: RuoYi-Vue-Plus 6.0.0 backend.
- `web/`: plus-ui-react 6.0.0 frontend.
- `platform/`: development metadata MySQL and Redis Compose services.
- `test/`: isolated SeaTunnel MySQL-to-PostgreSQL POC assets.
- `docs/`: PRD, architecture, POC, design and testing documentation.

Start with [docs/README.md](docs/README.md) and [docs/06-development/git-strategy.md](docs/06-development/git-strategy.md).
