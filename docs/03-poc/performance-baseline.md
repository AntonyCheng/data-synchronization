# 性能基线

## 测试条件

本轮只完成正确性和故障恢复样本，没有进行千万级容量压测。首轮样本为 5 行初始数据，持续 CDC 事件量为个位数，不能据此承诺生产吞吐。

## 指标

| 指标 | 目标/说明 | 实测 |
|---|---|---|
| 全量吞吐（行/秒） | 千万级表 | 待测 |
| 全量吞吐（MB/秒） | 含大字段 | 待测 |
| CDC 峰值吞吐（事件/秒） | 持续 10 分钟 | 待测 |
| CDC P95 延迟 | 源事件到目标提交 | 待测 |
| checkpoint 时长与大小 | 稳态任务 | 已观察 3-10 ms、stateSize=3（小样本） |
| SeaTunnel 重启恢复时间 | 从启动到继续写入 | 已观察约 30-60 s（含容器启动与 restore 提交，小样本） |
| MySQL CPU/IO 增幅 | 与空闲基线比较 | 待测 |
| PostgreSQL 写入资源 | CPU/IO/WAL | 待测 |
