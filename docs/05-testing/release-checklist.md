# MVP 发布检查清单

本清单对应 PRD v0.3 的 MVP 收口，不包含 Oracle、SQL Server、Kafka、Redis、MongoDB、ES、主动告警和高可用等后续阶段能力。

## 功能验收

- [x] MySQL/PostgreSQL 数据源迁移后连接测试成功。
- [x] 单表任务详情、目标兼容性和 CDC 前置检查可用。
- [x] COUNT 与 KEY_RANGE 数据核对可用，结果可持久化展示。
- [x] 引擎配置预览脱敏，未出现明文密码。
- [x] 任务组、缓存监控和历史任务状态可正常加载。
- [x] 前端控制台无新增错误，状态显示符合中文界面约定。

## 自动化和环境

- [x] `ruoyi-sync` Maven 回归通过。
- [x] 前端 TypeScript 检查和生产构建通过。
- [x] POC 清洁回归、稳定性检查和 50,000 行性能基线有结果目录。
- [x] 平台元数据库迁移脚本可重复执行且不改变既有任务数量。
- [x] 已生成离线交付前置清单；实际离线目录启动验证需在交付环境执行。

## 安全与运维

- [x] 数据源密码使用 `ENC_` 密文保存，主密钥不进入仓库。
- [x] 日志、配置预览和验收结果不包含令牌、密码或 AES 密钥。
- [x] 后端 Java 21 启动脚本、数据库迁移脚本和回滚边界已有文档。
- [ ] 审查 Git 工作区并提交 MVP 基线，排除 runtime、缓存、临时日志和敏感配置。

## 发布结论

仅当“离线交付包启动验证”和“Git MVP 基线”两项完成后，才将当前版本标记为可交付 MVP。后续目标端和告警能力另立 Phase 1.1/2/3 计划。
